Why a smaller emergency target can help

A distant savings target can make early progress feel irrelevant. Name the first layer after a concrete job—an urgent journey, a repair callout, or a week of essentials—then build outward once that layer exists.

A partial buffer is not a failed full buffer; it is protection you did not have before.
