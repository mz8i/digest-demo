Ask where the book changed its rules

A book club question better than did you like it

Most stories teach us how to read them, then complicate that lesson. Identifying the moment the rules shifted opens discussion without demanding a verdict.

  • What expectation had the book created?
  • Which detail broke it?
  • Did the new rule feel earned?
