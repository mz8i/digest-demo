Variation is part of the result

The useful error in a repeated measurement

Repeating a measurement exposes the spread created by tools, timing, and the object itself. Reporting that spread is more honest than choosing the neatest value.

A small range suggests stability; a wide range asks for a better method or a more cautious claim.
